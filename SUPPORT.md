# Support

ARMAMENT is currently a developer preview. No service-level agreement,
guaranteed response time, or production support commitment is offered.

## Before opening an issue

1. Read docs/setup.md and docs/troubleshooting.md.
2. Include the ARMAMENT commit SHA, OS, Python version, Docker Engine/Desktop
   version, and TrueForge version.
3. Attach relevant redacted logs from docker compose logs.
4. Describe expected and actual behavior and provide safe reproduction steps.

Never attach .env files, API keys, bearer tokens, customer logs containing
personal data, or unredacted audit records.

## Scope

Bug reports, reproducible installation failures, and feature requests are
welcome. Security vulnerabilities must be reported privately; see SECURITY.md.
